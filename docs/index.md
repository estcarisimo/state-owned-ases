# State-Owned ASes

A dataset of the Autonomous Systems (ASes) run by **state-owned Internet operators**:
984 ASes of companies in which a national government holds a majority stake, plus a
partial list of 301 minority state-owned ASes. Every AS comes with the quote and source
URL that confirmed state ownership. It is the dataset of the ACM IMC 2021 paper
[*Identifying ASes of State-Owned Internet Operators*](https://doi.org/10.1145/3487552.3487822).

!!! warning "This is an archive. The data is not maintained."
    Ownership was verified between **June 2019 and November 2020**. The dataset was last
    corrected in October 2021 and has not been re-checked since. Since then, operators
    have been privatized, nationalized, merged and renamed. ASNs have changed hands, and
    many evidence URLs no longer resolve. Use it as a **baseline** for that period, not
    as a picture of today's Internet. The 2026 restructuring changed only the file
    formats and fixed a few country codes and names ([changelog](changelog.md)). No
    ownership was re-verified.

## Where to start

- **Download the data**: the [`data/exports/`](https://github.com/estcarisimo/state-owned-ases/tree/main/data/exports)
  directory on GitHub. [Data and formats](data.md) explains what each file holds.
- **Load it** with pandas, DuckDB or SQLite: [Loading the data](loading.md).
- **Understand how it was built**, and how far to trust it: [Methodology](methodology.md).
- **Cite it**: [Citing](citing.md).
